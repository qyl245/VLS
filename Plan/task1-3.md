## 步骤一：实现 AIFit 两阶段分割

按 AIFit §4.1 复现，输入是**角度序列**（而非原始 3D 坐标，降低维度、提高鲁棒性）：

**阶段 A：自相关初始化**

1. 选一个主自由度角度（如深蹲用 `left_knee_flexion`，弯举用 `right_elbow_flexion`），或对多个角度取平均能量最高的一个。
2. 计算自相关函数 \(R_{PP}(\tau,s)\)（AIFit Eq.1），遍历 \(s\)（两端裁剪量）和 \(\tau\)（周期候选），选**第一个达到局部最大的最小 \(\tau\)** 作为 \(\tau^*\)。
3. 固定 \(\tau^*\)，遍历起始点 \(t_{start}\)，用平均相似度 \(A_{avg}\)（AIFit Eq.2）选**第一个局部最大**的 \(t_{start}^*\)。相似度定义为负的 MPJPE——在角度空间里改为**负的角度序列欧氏距离**。

**阶段 B：约束优化细化**

1. 以 \(T(t_{start}^*, \tau^*)\) 为初始化，放弃固定周期假设。
2. 用均匀采样函数 \(U(T_i, n_S)\) 从每个 rep 区间采 \(n_S\) 帧（非整数时刻线性插值），计算推广的 \(\hat{A}_{seq}\)（AIFit Eq.4）。
3. 最大化 \(\hat{A}_{avg}\)，约束：相邻 rep 间隔 \(> \delta\)（防平凡解），最后一个 rep 不超出 \(\tau^*\) 范围（AIFit Eq.5–6）。
4. 超参 \(n_S\)、\(\delta\) 在验证集上网格搜索，记录最优值。

**实现注意**：

- 角度序列的 NaN（visibility 低）用前后最近有效值填充**仅用于分割**，并记录填充比例；分割边界落在 NaN 段时标记“低置信分割”。
- 主自由度角度的选择可自动化：对每个候选角度算运动能量（AIFit Eq.7），取能量最高的作为分割信号。

## 步骤二：峰值检测基线

按 IMCD §4 的 prominence-based 方法实现对照：

1. 对同一主自由度角度序列做 Gaussian 平滑。
2. 找局部极大值，计算 prominence \(\Delta P_k\)（峰值与其两侧谷值最小值之差）。
3. 保留 \(\Delta P_k > \tau\)（IMCD 用 \(\tau=0.2\)，你的角度范围是度，需按数据分布调整，建议取角度动态范围的 10–20%）。
4. 对每个保留峰值，向前后找最近的局部极小值作为 rep 起止。

**这个基线很重要**：它代表“不用训练、不用优化”的最简方法，如果 AIFit 两阶段没比它好多少，说明你的角度特征或姿态质量有问题，需要回头查。

## 步骤三：在 Fit3D 上定量评估

**数据**：Fit3D 测试集 3 受试者，2,964 个手动标注的重复时间戳。
**指标**：IoU（AIFit 表 2 协议），对每个视频的所有 rep 取平均。

**三组对比**：

| 输入                       | 方法         | 预期                              |
| -------------------------- | ------------ | --------------------------------- |
| Fit3D GT 3D 姿态           | AIFit 两阶段 | IoU ≈ 0.73（AIFit 表 2 GT 结果） |
| Fit3D GT 3D 姿态           | 峰值检测     | 作为对照，看差距                  |
| MediaPipe 姿态（任务 1.2） | AIFit 两阶段 | 应低于 GT，但不应崩溃             |

**记录**：每个动作的 IoU、失败案例（IoU < 0.5 的视频）、失败原因初步判断（遮挡？节奏太快？角度信号太弱？）。

**如果 Fit3D 未到位**：

- 用 QevD 长视频做定性验证：可视化分割边界叠加在视频上，人工看是否切在每个 rep 的起止。
- 用 Sana 的 CSV 角度序列做快速 sanity check（有 16 类动作，可看分割是否合理）。
- 定量部分标“待 Fit3D”，不阻塞周 2 其他任务。

## 步骤四：消融与鲁棒性记录

**消融**（在 GT 姿态上做，控制变量）：

1. 主自由度角度选择：自动能量最高 vs 固定（如固定用膝角）→ IoU 差异。
2. 平滑：无平滑 vs Savitzky-Golay → IoU 差异。
3. 阶段 A 单独 vs 阶段 A+B → 优化带来多少增益。

**鲁棒性**：

- 对 GT 姿态加高斯噪声（模拟姿态估计误差，噪声标准差取任务 1.3 记录的 MediaPipe 角度误差量级），看 IoU 下降曲线。这直接对应 AIFit 表 2 的“姿态质量 → 分割精度”关系，也是你未来论证“IMU 在遮挡下补位”的基线。

## 决策点（与任务 1-4 直接相关）

1. **AIFit 两阶段是否达标**（GT 姿态 IoU ≥ 0.70）？达标 → 定版；不达标 → 查角度特征或换主自由度选择策略。
2. **MediaPipe 姿态下 IoU 掉多少**？掉太多（如 < 0.55）→ 后面换 RTMPose/微调 MubyNet，或加峰值检测融合。
3. **失败是否集中在特定动作/视角**？如果是侧面深蹲的遮挡 → 正好是 IMU 补位的论证素材，记录下来。
4. **是否需要在周 3 加入“多角度融合分割”**（如膝角 + 髋角 + 躯干角联合自相关），还是单角度够用？
